# emails-parceiros

HTMLs dos emails de parceiros RD Station.

Pastas
- compelling: campanhas de compelling (ex. 2026-11-23 Katana + BF + Migração)
- katana: emails da Operação Katana
- retrospectiva-2026: email de retrospectiva do ano
- editais: modelos e disparos de editais
- news-radar: newsletter mensal
- aniversario-parceria: email mensal de aniversário de parceria
- _templates: blocos e modelos base

Padrão de nome: AAAA-MM-DD_nome-da-peça/ com os HTMLs e uma pasta imagens/.
